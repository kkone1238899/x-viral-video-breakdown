## 拉片四维拆解表

拿到任何一条爆款视频，按这个拆（我们自己的方法，持续打磨中）：

1. **钩子（0–5 秒）**：第一帧画面是什么？第一句话说什么？为什么让人停下？
2. **节奏**：每几秒一个信息点 / 反转？哪里快、哪里慢？
3. **镜头语言**：景别变化、运镜、转场各用了几次？哪一处是记忆点？
4. **可复用公式**：这条爆款抽象成一句话模板是什么？（例：反常识开头 + 三个证据 + 反转结尾）

## 爆款方法拆解案例

用上面的四维表拆出来的真实案例（拆的是爆款生产方法本身，照着抄就能用）：

### 案例 1：36 条视频涨粉 70 万的 AI 短剧账号

拆解对象：[@ChrisSlacker 的方法拆解帖](https://x.com/ChrisSlacker/status/2109199405597532412)

- **钩子**："36 条涨粉 70 万"——结果数字前置，做账号的人 0 秒被抓住
- **节奏**：结论先行（三一致）→ 7 段提示词链（方法）→ 8 个工具（弹药），信息密度递增，每往下读都有获得感
- **表达结构**：正文给骨架，评论区补血肉（角色卡固定字段原样粘贴的实操细节在评论区），形成"正文 + 评论"双层
- **可复用公式**：惊人结果 + 可复制流程 + 工具清单 + 评论区补细节 = 一篇能涨粉的方法帖

**怎么用它搞钱**：照这个公式拆你所在赛道的爆款账号，输出拆解帖给自己引流；或把"三一致"流程打包成短剧代运营服务。

### 案例 2：40 秒儿童科普漫剧的量产 SOP

拆解对象：[@AI_DVD6 的量产帖](https://x.com/AI_DVD6/status/2106718752624541784)

- **钩子**："7 次生成只用 3.5% 额度"——省钱数字钩子，精准打中被 AI 烧钱吓退的人
- **节奏**：约束先行（2 人物 1 场景）→ 绕坑技巧（避口型）→ 省钱决策表，层层解决"我做不出来 / 做不起"的顾虑
- **表达结构**：每个技巧都配"为什么"（定妆照是身份锚，不传就跑偏），方法 + 原理双给，读者能举一反三
- **可复用公式**：痛点约束清单 + 绕坑技巧 + 省钱决策表 = 一套可直接开干的 SOP

**怎么用它搞钱**：复制模板换赛道（历史 / 健康 / 育儿），每天量产发小红书起号接广告。

### 案例 3：30 秒 AI 短片《零点当铺》全流程

拆解对象：[@yangleiocx3 的全流程教程](https://x.com/yangleiocx3/status/2108757102512472453)

- **钩子**："教程 + 代码全免费"——免费钩子，做短剧的人无法拒绝
- **节奏**：做减法（1 场景 1 人物）→ 锁定（首帧母图）→ 拼装（最稳定片段）→ 后期（配音字幕），每一步都在降低难度
- **表达结构**：具体参数全公开（5 镜各取 6/4/6/8/6 秒、配音从 0.92 秒起），读者能 1:1 复刻
- **可复用公式**：免费钩子 + 全参数公开 + 可复现脚本 = 信任状拉满的教程帖

**怎么用它搞钱**：照参数复刻一条发抖音 / 视频号，教程类内容天然吸同行粉；接"AI 短剧代做"单。

### 案例 4：像素级拉片 Skill——把对标拆成可执行的复刻规格

拆解对象：[@Luca23Max 的拉片 Skill 长文（X Article）](https://x.com/Luca23Max/status/2113305031688736882)（配套开源仓库：[xiaolu-ai26/video-close-reading](https://github.com/xiaolu-ai26/video-close-reading)，MIT）

适用场景：想把对标视频拆成可执行复刻规格的剪辑 / 运营，或想给 Agent 装拉片 skill 的创作者。

- **五维拆解框架**：画面（观众先看谁→看哪里，主次关系）/内容（每段回答什么问题、留下什么问题）/剪辑（为什么在这里换画面，不机械规定切镜频率）/声音（人声/音乐/环境声/音效/停顿五类分别观察）/设计（文字图形是否帮人理解）
- **四层观察粒度**：先看全片（弄清目标）→划分段落（任务交接）→回到关键镜头（人物/画面/信息如何连接）→对疑问处补连续帧（切点/字幕/动效），不一开始就钻细节
- **"像素级对标"**：需要时能量到原片帧号/位置/比例——统一时间基准用解码帧序号+PTS，不用"秒数×平均帧率"猜位置（可变帧率会错）；只想理解结构先做快速拆解，准备复刻某段动效再深入那几秒
- **字幕时间点 ≠ 口播切点**：视觉文字边界与音频起音边界剥离开分别记录。案例：开场字幕 f76→f77 换句（≈2.567 秒），不能推出声音在同一帧开始——复刻时剪出呼吸感怪异的片子多源于此
- **发布前检查清单（小红书复盘视角转诊断）**：2 秒退出率/前 5 秒留存/前一分钟回报/平均观看时长/全片完播/互动（赞/藏/评/分享分开写理由）/内容深度（看完能做什么），七项三档支持度，不给"爆款总分"
- **报告输出**：本地 report.html（七维评分+可展开"时间证据/核心理由/替代解释/实操改法"）+ 时间线事件轴（已复核事实 vs 候选推断分开写，未验证的留空不编）
- **迭代闭环**：拆解对标→提取工程规格→单变量制作（"控制变量，单点突进"，一次只改一处）→发布拉真实后台数据→对照时间线找断点；附四种可直接复制的任务提示词：快速拆解/只拆开头五秒/可视化报告/复刻规格

**怎么用它搞钱**：把 skill 装进 Codex / Claude Code，接"爆款视频拆解"咨询单；或按这套方法论做拆解帖/视频引流，再转短剧代运营。

### 案例 5：影视飓风 28 秒三分屏自证——"过程可验证"拉片

拆解对象：[@AYi_AInotes 的 28 秒时间轴拆解帖](https://x.com/AYi_AInotes/status/2113216170115400010)（拆的是影视飓风 Tim 英文号 28 秒实拍自证视频）

适用场景：做 AI 内容常被质疑"AI 造假"，或想给作品加信任状的创作者 / 团队。

- **背景**：影视飓风 Tim 一条 1483 万浏览的 iPhone 运镜大片，丝滑到被老外怀疑是 AI 生成，被迫发 28 秒零解说竖屏三分屏自证：上屏=机械臂软件时间线+三维轨迹曲线，中屏=最终成片，下屏=鱼眼相机同步拍电影机实拍过程
- **28 秒抽帧分镜**：0–2 秒黑场俯拍桌面（黄金钩子）→2–5 秒三屏瞬间对齐→5.3–16.5 秒白色长廊高速甩镜（大动态炫技，真实物理运动模糊）→16.5–21.5 秒暗调桌面毫米级掠过手机（微距精度）→21.5–28 秒约 120°F 热成像收尾，全程只靠 BGM 卡点、零解说
- **核心洞察**："信任的锚点从结果变成了过程"——AI 能以假乱真之后，谁能把后厨监控/颠勺特写/火候表同屏甩出来，谁拿走最高级的信任；"过程可验证"可能变成和画质同等重要的竞争力
- **反向迁移模板（AI 创作者照抄）**：上屏放提示词工程/节点工作流/终端日志，中屏放最终成片，下屏放编辑器实时调试录屏——每个场景 5–10 秒配乐直出，被质疑"AI 造假/洗稿"时直接甩视频，不用写小作文自辩
- **2 个实战动作**：① 从立项第一天就架好记录过程的副机位/录屏——过程资产以后比成品还值钱；② 三分屏无声自证模板（底层控制逻辑+最终成品+物理现场/操作录屏）
- **评论区金句**：@vyn_frames "现在丝滑反而成了嫌疑"；@HSkyer99871 "以前创作者要证明'我有实力'，现在要证明'这是我做的'"

**怎么用它搞钱**：给客户/甲方交付时附三分屏过程视频，溢价接单；做"AI 作品可信度包装"教程引流。

### 案例 6：Kimi K3.1 24 秒预告片逐帧拆解——从技术细节反推产品方向

拆解对象：[@MinLiBuilds 的逐帧拆解帖](https://x.com/MinLiBuilds/status/2113491183318311382)（拆的是 Kimi K3.1 官方 24 秒预告片，约 12.9K 浏览）

适用场景：想学"热点预告片怎么拆"的创作者 / 关注 AI 视频新信号的人。

- **第一步：抓开场闪现的终端**：预告片开头一闪而过的终端里藏着关键 Prompt——用 Three.js 构建复杂的程序化 3D 场景、不依赖外部 3D 素材。热点视频的第一帧往往藏着最大的信息量，拉片先定格开头
- **第二步：量出剪辑密度**：24 秒塞进近 100 个镜头，最快每 0.125 秒闪切一次——数字是最好的钩子，也是衡量"信息密度"的尺子，先量再评
- **第三步：列视觉元素清单**：克莱因瓶、洛伦兹吸引子、分形生长、3D 流体、粒子风暴、黑洞——把每个元素点名列出来，读者立刻知道"这段视频在秀什么技术"，清单式写作降低阅读门槛
- **第四步：从技术细节反推产品方向**：从"纯代码生成 3D 世界"大胆押注——Kimi K3.1 这次要卷的是视觉编程：一句话生成复杂 3D 世界，自动写 Shader、物理模拟、交互动画，甚至完整游戏
- **第五步：再往前看一步**：Agent 自己写代码、渲染、剪辑，直接交付成片——从单条拆解给出一个可讨论的行业判断，这是评论区被点燃的原因，拆解帖的结尾要留一个"可争论的结论"

**怎么用它搞钱**：热点预告片上线 2 小时内发逐帧拆解帖/视频抢流量，"24 秒 100 镜"这类数字钩子自带传播；或把"终端抓 Prompt → 量剪辑密度 → 列元素清单 → 反推产品方向"做成固定拆解模板接单。

### 案例 7：Refs 镜头蓝图拆解——"给 AI 具体到每一秒的镜头结构"

拆解对象：[@CY160909 的 Refs 拆解案例帖](https://x.com/CY160909/status/2113491102359564798)（用 Refs 工具拆 @stephanlivera 的 15 秒 Claude 动效短片，公开样例：https://refs.video/v/2103315922098470926）

适用场景：用代码做动效短片、想让 AI 按精确镜头结构出片的创作者。

- **核心方法论**：比起让 AI"做得高级一点"，给它具体到每一秒的镜头结构，才更容易控制制作过程——精确的镜头蓝图胜过模糊的风格描述，这是代码做视频与提示词做视频的根本区别
- **反直觉数据**：15 秒、10 个镜头、9 次切换，却没有一次精准踩音乐节拍（BGM 约 128 BPM）——"卡点"不是铁律，拆解时要实测而不是想当然
- **切点细节**：首个切点在 1.88 秒；开场图形先长成标志；中段切换图表、几何、纹理；结尾用几张极短字卡提速，再停在品牌卡上——每个转场都有功能，不是装饰
- **可复用的顺序模板**：先建立一个视觉符号 → 展示几种变化 → 短镜头提速 → 给品牌留下完整停顿
- **工具化**：Refs（refs.video）整理了 4,088 部品牌宣传/动效/创意短片，记录镜头切点位置、持续时长、开头铺垫、结尾收束；Pro 版经 MCP 把完整蓝图交给 Claude Code / Codex / Cursor，用 Remotion 辅助制作——"拆解库 + MCP 蓝图"是一条完整的生产链路
- **协作建议**：把每一步的画面和时长写进制作 Brief，之后才能逐镜头检查，而不是只会对 AI 说"再有质感一些"——给 AI 的指令也要先结构化

**怎么用它搞钱**：用"镜头蓝图"法接品牌动效短片代做单（先出蓝图再出片，交付物更专业、报价更高）；或做 Refs 类工具的实测教程引流。

### 案例 8：Kimi K3.1 首帧技术分析——"整个视频是从代码开始的"

拆解对象：[@FiniYang 的首帧分析帖](https://x.com/FiniYang/status/2113523183223738764)（@MinLiBuilds 逐帧拆解的引用链延续，为其自回帖线程中的一条）

适用场景：想学"代码做视频"拉片视角的人；看 Kimi K3.1 视觉编程信号的创作者。

- **首帧即证据**：首帧终端显示 kimi-k3.1 / thinking: high / context: 0/1M / Kimi Code Desktop——拉片时别跳过第一帧，技术参数往往写在最显眼处
- **代码量数字化**：155 行 Three.js 代码——把"代码生成"落到具体行数，读者立刻有体感，数字比形容词可信
- **技术细节清单**：Mulberry32 随机数算法、固定种子 202604、高斯包络线、球面三角函数——点名具体技术名词是这类拆解帖"干货感"的来源，外行看热闹、内行看门道
- **Prompt 回扣**：不依赖外部 3D 素材、直接用代码生成复杂的 3D 场景——和 @MinLiBuilds 抓到的终端 Prompt 互相印证，引用链上的拆解可以互相佐证
- **一句话结论**："整个视频是从代码开始的"——把技术细节收束成一句可传播的判断，好拆解帖的结尾都是一句金句

**怎么用它搞钱**：首帧/终端截图是拆解帖的天然钩子，照这个模板（首帧参数 → 代码量 → 技术名词 → Prompt 回扣 → 一句话结论）拆其他 AI 视频预告抢热点流量。

### [Lapian Notes（拉片笔记）](https://github.com/bkingfilm/lapian-notes) ⭐734（2026-10-23 经 API 核验，MIT）

一句话：AI 辅助的电影拉片工具——本地抽帧+字幕打包发任意 AI，导回结果自动生成剧情泳道时间轴、结构树与观众情绪曲线，全本地运行不上传数据；适合想系统学电影叙事/批量拆爆款结构的创作者。

- **上手要点**：
  1. 导入 MP4 → 自动抽帧（1 秒 1 帧）+ 配字幕 → 一键生成 AI 分析包（ZIP）
  2. 把包发给 ChatGPT / Kimi / 豆包等任意 AI（不绑定服务、无需 API key），导回 JSON 自动生成泳道时间轴/结构树/情绪曲线
  3. 浏览器直接打开在线试用版（l.bking.film），下载完整版才有本地转码与自动搜字幕
- **怎么用它搞钱**：用它批量拉片同赛道爆款，输出"泳道时间轴+情绪曲线"拆解帖/视频做内容引流；或接"竞品视频深度拆解"咨询单。
